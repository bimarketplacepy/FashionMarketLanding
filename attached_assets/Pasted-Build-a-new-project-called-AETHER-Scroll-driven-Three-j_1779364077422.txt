Build a new project called AETHER. Scroll-driven Three.js art essay 
showcasing six impossible physical phenomena. This prompt sets up the 
scaffold only. Do not build any of the Three.js phenomena scenes yet.

PROJECT SETUP

- React 18 + Vite + TypeScript
- Tailwind CSS for layout only (no component library)
- Three.js (latest stable)
- GSAP + ScrollTrigger
- Tone.js
- @studio-freight/lenis for smooth scroll

VISUAL IDENTITY

- Background: pure black #000000 throughout the entire site
- Primary text: off-white #fafafa  
- Accent: pale violet #b8a0ff (used sparingly, for section numbers only)
- Display font: Italiana (Google Fonts) for large display type
- Mono font: JetBrains Mono for labels, numbers, technical text
- All UI text is small. The phenomena are the show.

PAGE STRUCTURE

A single long vertical scroll containing 8 sections, each 100vh tall:

Section 0 — INTRO
Section 1 — I. SINGULARITY
Section 2 — II. AURORA  
Section 3 — III. CRYSTALLINE
Section 4 — IV. CAUSTICS
Section 5 — V. PARTICLE STORM
Section 6 — VI. WORMHOLE
Section 7 — OUTRO

Each phenomena section (1-6) will eventually contain its own full-screen 
Three.js canvas with a different shader scene. For now, build empty 
placeholder sections with the labels and architecture in place. The 
scenes themselves come in subsequent prompts.

LENIS SMOOTH SCROLL

Initialise Lenis at the root. Configuration:
- Duration 1.2 seconds
- Easing: cubic ease out
- Smooth mouse wheel and touch
- Sync GSAP ScrollTrigger to Lenis on every tick

Fixed position, right side of viewport, vertically centred:
- A thin vertical line 200px tall, 1px wide, off-white 20% opacity

starts scrolling.
